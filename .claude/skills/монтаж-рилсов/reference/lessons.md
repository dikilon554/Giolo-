# Грабли и решения (накоплено в работе)

## Время слов и склейки
- **Время слов у Whisper плывёт до ±0,3 с (иногда больше).** Резать и ставить субтитры по нему нельзя. Привязывай к тишине из аудио: `silencedetect` (для резки: `-35dB d=0.2`; для привязки слов мягче: `-32dB d=0.12`). Строй монотонную кусочно-линейную «кривую времени» Whisper→реальное время по якорям (конец слова перед тишиной ↔ начало тишины, начало слова после ↔ конец тишины), затем `np.interp`. Так субтитры попадают в среднем в 0,12 с.
- Режь **середину** тишины, оставляя 0,12 с (при длине тишины <0,18 с не режь). Границы блоков кадра = середина оставшейся паузы. Номера кадров считай через `new_f(t)` по списку резок (целые кадры).
- В конце ролика Whisper галлюцинирует («Субтитры создавал…», «Субтитры подогнал …»): это не речь, игнорировать.
- Паузы внутри предложения (перечисление «день, неделю, месяц») тоже можно подрезать до 0,12 с, если пользователь утвердил таблицу.
- Расшифровку готового ролика всегда сверяй с оригиналом **без пунктуации**; лишний «слово-токен» из знаков препинания не ошибка.

## Видео и цвет
- Записи экрана — переменный fps 60: `fps=25` после `setpts`, потом `trim=end_frame`.
- Нетегированный 720p/1080p аватар в плеерах читается как bt709: при декоде в RGB явно `in_color_matrix=bt709`; обратно `out_color_matrix=bt709` + теги.
- **`cv2.VideoCapture` не использовать для цветокритичной обработки** (читает как 601). Декодируй ffmpeg в rawvideo, обрабатывай, кодируй обратно ffmpeg.
- `cv2.remap` требует float32-карты (`mx.astype(np.float32)`).
- PNG-наложения в ffmpeg: `format=rgba,scale=out_color_matrix=bt709:out_range=tv,format=yuva420p`, иначе красный/кремовый цвет уезжает. Для покадровой графики быстрее слать сырой RGBA в `overlay` (stdin) или композитить в Python (только bbox ненулевой области).
- Не-9:16 вставки: не обрезать по бокам. `zscale=w=1080:h=-2` + `pad`.
- 60 fps → 25 fps: сначала скорость (`setpts`), потом `fps`. Короткие клипы тянуть стоп-кадром, не замедлением <0,8.
- YuNet возвращает линию бровей, не макушку: макушка аватара ≈ y 450 на 1920. Карточки над головой делай нижним краем ≤ 420.

## Звук
- Две проходки loudnorm точнее, но для микса достаточно одной в конце (`loudnorm=I=-14:TP=-1.5:LRA=11`).
- Музыка вступает на ударе: `adelay` на мс, перед ним `afade` на 0,06 с. Затухание в конце считать от старта музыки.
- Анализ частот: доли энергии бас/середина/верх (40–150 / 150–2000 / 5000–10000 Гц), сравнивай микс с миксом конкурента. Не подгоняй по числам слепо: итоговое слово за ухом пользователя.
- Голос от музыки не отделить без нейросети (нет доступа к весам): чужой трек из видео с голосом не извлекаем.

## Субтитры и графика
- Эмодзи в Pillow: `ImageFont.truetype('NotoColorEmoji.ttf', 109)` + `text(..., embedded_color=True)`, затем уменьшить.
- Длинные слова при «выскакивании» вылезают за кадр: ограничивай масштаб `(W−24)/ширина`.
- Слова вплотную («ИЧТО,») — пробел делай от кегля (≈0,3·размер), знак препинания не отделяй.
- Субтитры закрывали важное на вставках (просмотры, суммы, кнопка): перед выдачей смотри каждую вставку отдельно.
- Дубли графики (нижняя панель с тем же текстом, что заголовок) пользователь не хочет.
- Карточки/цифры держи до конца фразы, иначе итог не успевает прочитаться (наступали: гас на «9 668» вместо «11 250»).

## Анимация из картинки
- Исходные «готовые ролики» от генератора = слайд-шоу из статичных картинок с растворением: движение 0,00 по измерению. Нужно создавать движение самим (глубина + наезд + частицы). Измерение: средняя разница кадров через 0,2 с на уменьшенном кадре.
- Карта глубины: `depth-anything/Depth-Anything-V2-Small-hf` через `transformers.pipeline('depth-estimation')`, билатеральный фильтр + размытие σ=3, плоскость нуля около персонажа (D0≈0,62).
- Вращение сферы из одного полушария: исходная картинка → диск (minEnclosingCircle, R·0,965), де-светим (альбедо = кадр / размытая яркость), вращаем точки на сфере, пере-светим, край диска оставляем оригинальным. Скрытая сторона достраивается зеркалом, у края размыть. Предел ~20–25°.

## Сеть и окружение
- `remotion.media` закрыт: Remotion не скачает браузер. Запуск с `--browser-executable=/opt/pw-browsers/chromium --chrome-mode=chrome-for-testing`.
- HF: `HF_HUB_DISABLE_XET=1`; нужные хосты см. `setup.md`.
- Drive: `googleusercontent` (doc-*-6k) — отдельный хост, без него `gdown` падает на скачивании файла.
- Окно подтверждения (создание/обновление окружения) на старом мобильном приложении не показывается: просить открыть сессию в браузере.
- Все долгие шаги (рендер 2–3 мин) делать в одном вызове с `timeout`; результаты и превью отправлять сразу.

## Процесс
- Пользователь предпочитает: сначала план и «ок» (особенно для резок), потом сборка, потом честная самопроверка с отметкой «ок / исправить / проверьте на слух».
- Всегда говори, где результат отличается от плана (скорости вставок, обрезки, замена элементов). Не скрывай.
- Если что-то неверно в собственных предыдущих утверждениях (например про паузы в плане), прямо признай и исправь.

## Под каждого аватара — своя раскладка плашек (важно, красный флаг для пользователя)
- **Нельзя копировать позиции карточек/баннеров из прошлого рилса.** Для каждого нового аватара заново смотри жесты по кадрам (контактный лист `fps=5` на нужные секунды) и ставь плашки туда, куда он показывает, либо в свободную зону.
- **Если в момент плашки жеста нет** (аватар сидит спокойно), ставь плашку **над головой** (нижний край ≤ y 420, макушка ≈ y 450), как карточку ChatGPT: заметно, глаз цепляется, лицо и руки свободны.
- Баннер канала: целиком (без обрезки названия и подписчиков), ширина ~620 px (чуть крупнее обычного, не гигантский), позиция (230, 196). Карточка ChatGPT: 640×360, позиция (220, 60). Обрезка по ширине режет название («Записки выжи…»): проверяй.
- Если реплика короткая и записи нет, делай статичную иконку-карточку вместо ролика (так уже работало).
- **Музыка не обязательна в каждом рилсе.** Спрашивай/предлагай два варианта (с музыкой и без) или делай оба: без музыки = `loudnorm` на чистом голосе поверх `video_noaudio.mp4`.

## Музыка и разборчивость (рилс №4)
- **Проверяй, не заглушает ли музыка слова:** сравни расшифровку Whisper версии с музыкой и без. При −9 дБ с обычным сайдчейном пропали два слова; при −12 дБ и более жёстком сайдчейне (ratio 8, threshold 0.02, release 300) всё на месте. Подбирай громкость по этому тесту, а не на глаз.
- Конкурентскую музыку напрямую взять нельзя (в одной дорожке с голосом); пользователь присылает трек файлом. Музыка в рилсе по желанию пользователя: бывает с самого начала (как у конкурента) или после хука, уточняй.
- Секундомер: на рилсе, где идёт задача «за N», строй счётчик в реальном времени ролика, фиксируй на ключевой фразе.
