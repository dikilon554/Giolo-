## Конкурент (образец структуры)
0–6,3 с аватар (заголовок + цифры на экране ноутбука, субтитров нет) → 6,3–14,2 записи экрана (YouTube, поиск, выплаты Facebook/TikTok, субтитры 70 %) → 14,2–17,4 аватар → 17,4–27,3 записи сайта (вставил промпт, generate) → 27,3–29,7 готовый ролик → 29,7–39 аватар (CTA с зелёным ключевым словом). ~17 склеек за 39 с, только прямые, без зумов; музыка 123 BPM: кик по четвертям, хлопок на 2/4, синкопированный бас, хэты на «и», бас тихий вначале, полный к ~12 с; громкость −14,2 LUFS.

## Сценарий нового рилса (пример для сопоставления «реплика → вставка»)
Реплики аватара с метками вставок (так присылает пользователь, метки в скобках):
1. «Каждый день, каждую неделю, каждый месяц. Тебе не нужно искать подработку, просто сделай вот это.» (аватар поднимает палец вверх, цифры 375 $, 2 625 $, 11 250 $)
2. «Зайди на YouTube и поищи вирусные видео в стиле «Что, если…». Посмотри, сколько они набирают просмотров.» (экран YouTube)
3. «Вот сколько YouTube платит за миллион просмотров. А вот столько платит TikTok.» (скриншоты выплат)
4. «И вот как ты можешь сделать то же самое, чтобы получить выплаты на всех этих платформах.» (аватар)
5. «Зайди в софт Forge Vision. Вставь этот текст. Выбери формат… И выбери этот стиль. И просто нажми «Сгенерировать». И через несколько минут ты получишь видео, прямо как это.» (интерфейс Forge Vision и готовый ролик)
6. «Остаётся просто выставить этот ролик на YouTube и TikTok, чтобы собрать просмотры.» (аватар) — в записи сказано «охваты», в субтитрах пишем **как сказано**; «софт» пишем как в сценарии
7. «И это не обязательно должна быть именно эта ниша. Ты можешь делать ролики с абсолютно разными стилями. В Forge Vision их больше 50.» (аватар + пролистывание стилей)
8. «Хочешь сделать такой же контент? Забирай демо-доступ по ссылке в шапке профиля.» (аватар, CTA)

## Скрипты проекта (`scripts/`)
| Скрипт | Для чего |
|---|---|
| `words.py` | расшифровка по словам (faster-whisper) → `монтаж_слова/<имя>.words.json` |
| `transcribe.py` | расшифровка по фразам GigaAM-v3 (+ .srt) |
| `reel_new.py` | **пайплайн рилса по конкуренту** (резка пауз, блоки, субтитры, заголовок, карточка, CTA, музыка). Шаблон: для нового рилса скопировать и менять `blocks`, `CAPS`, индексы слов, клипы, позицию карточки |
| `track_beats.py` | сетка битов трека (BPM, фаза, старт ~12 с) |
| `music_hype.py` | запасной синтез бита 123 BPM |
| `music.py` | старый тёмный бит 128 BPM (для справки) |
| `timeline.py`, `montage.py`, `montage2.py`, `montage3.py` | пайплайн старого рилса (две крупности, субтитры в разных стилях) |
| `sub_samples.py` | макет 2×2 стилей субтитров на одном куске |
| `animate_still.py`, `animate_still_nocap.py` | «ожившее фото»: глубина, наезд, пылинки, субтитры (вторая — без плашки) |
| `animate_earth.py` | анимация вращающейся Земли с торможением |
| `insert_immortal.py` | вставка «Бессмертный» со статичным кропом (устарела, есть анимированная) |
