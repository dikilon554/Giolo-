# Разнообразие: форматы, вводные про софт, CTA (от 26.11.2026)

Проблема: все рилсы шли по одному скелету «YouTube → ChatGPT → Forge Vision → готово». Это red flag. Решение — адаптивный подход (SKILL.md), здесь — факты про софт, вводные и CTA.

## Что известно про Forge Vision (используй как факты)
- По тексту сценария делает готовый ролик: визуал, анимация, озвучка, монтаж.
- **Можно вставить ссылку на ролик YouTube** — без ChatGPT (из ролика эксперта на основном аккаунте).
- Формат 16:9 / 9:16, библиотека 60+ стилей (`styles.md`), есть «Свой стиль».
- На компьютере: видео (Veo), свой стиль и монтаж. С телефона: ролик из фото с озвучкой.
- Подача эксперта: «настоящая машина по производству YouTube Shorts», «полная студия в одной подписке», «безлимитные видео с нуля».
- **Что можно снять записью экрана, а что — только моушн-графикой.** У пользователя демо в Telegram-приложении на планшете (ПК/Mac нет). Записью экрана — только то, что есть в Telegram-приложении (выбор стиля, создание ролика, готовые ролики). Вставку ссылки на YouTube, функции десктопной программы и загрузку на YouTube показываем **моушн-графикой** (как в ролике эксперта: поле со ссылкой, заставка с логотипом, меню «Создать → Загрузить видео»), а не записью экрана.
- **Вставка ссылки на YouTube** — берём моушн-графику из ролика эксперта с основного аккаунта (≈11–23 с: копирование ссылки, заставка Forge Vision, поле со ссылкой, библиотека стилей, меню загрузки YouTube) и монтажёр (Claude в другом чате) меняет в ней русские надписи. Обязательно: «Полная студия в одной подписке» → без слова «подписка» (например, «Машина по производству роликов»). В сценарии указывать это прямо во вставке.
- Публикация на YouTube — вручную (в сценарии не обещать автопубликацию).
- Подарки и промокоды для новых пользователей реально есть (подтверждено 26.11.2026) — CTA с подарком можно использовать.
- Не выдумывай функции сверх этого (автопубликация, переводы и т. п.) — сначала спроси пользователя.
