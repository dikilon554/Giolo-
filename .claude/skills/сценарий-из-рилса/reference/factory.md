# Контент-завод (сценарии со звёздочкой *)

## Что это
**Контент-завод** — когда по **одной дорожке** (один записанный ролик ИИ-аватара: голос и картинка) мы делаем **много разных рилсов**, меняя только вставки и хуки, чтобы выкладывать их без повторов и «палева». Сценарий для завода должен быть написан так, чтобы голос не был привязан к конкретной нише или экрану.

## Когда ставить `*` (сценарий подходит для завода)
Ставь звёздочку к названию сценария, если выполняется **всё**:
1. **Голос универсален:** в репликах нет конкретной ниши, названия видео, суммы, привязанной к вставке (говорим «любое вирусное видео», «любая ниша», «сколько мне принесла монетизация»). Цифры, которые зависят от экрана, показываются во вставке, а не произносятся.
2. **Вставки подменяемы:** всё, что отличает один рилс от другого, лежит во вставках (какое вирусное видео в YouTube, какой промпт в ChatGPT, какая тема/стиль в Forge Vision, какой готовый ролик, какая статистика). Реплики остаются теми же.
3. **Структура универсальна:** хук → YouTube → ChatGPT → Forge Vision → готовый ролик → доказательство → CTA, как в эталонах.
4. **Хук заменяем:** первая 1–2 реплики можно заменить другим вариантом **такой же длительности** без ломки остальной дорожки.

Если хоть одно не выполняется (голос про конкретную нишу, зависит от конкретной цифры или события), ставь без звёздочки и напиши почему.

## Что добавить к сценарию со звёздочкой
1. **Варианты хука (3–5):** замена первой реплики/двух, примерно того же времени (±0,5 с), чтобы по одной дорожке получать разные рилсы. Примеры подачи: сумма («20 тысяч долларов за…»), срок («Давай заработаем тысячу за минуту»), период («Каждый день, неделю, месяц»), вопрос («Хочешь зарабатывать на YouTube без лица?»). Для каждого укажи, какая вставка идёт с хуком.
2. **Таблица подмен вставок:** что менять от рилса к рилсу.
   | Слот | Что меняем | Примеры |
   |---|---|---|
   | Вирусное видео | ролик в нише | космос, «что если», выживание, история |
   | Промпт ChatGPT | тема в `[название вирусного видео]` | |
   | Forge Vision | текст сценария, формат, стиль | другой стиль из 50+ |
   | Готовый ролик | другой результат | |
   | Статистика | другой скриншот | |
3. **Что нельзя менять** (дорожка зафиксирована): порядок реплик, длительности пауз, текст голоса вне хука.
4. **Разные «палевные» места:** предлагай менять хук, порядок вставок внутри блока, заголовок, жёлтые ключевые слова в субтитрах, музыку (чтобы рилсы не были копиями друг друга).

## Формат вывода для завода
```
[Название] *

(основной сценарий в формате «реплика + (вставка)»)

Варианты хука:
1) «...» (длительность ~N с, вставка: ...)
2) «...» ...

Подмены вставок: (таблица)
Что фиксировано: ...
```
