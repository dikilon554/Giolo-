# Формат сценария (как пишет пользователь)

Каждый блок: **реплики аватара** (1–3 коротких предложения), затем **в скобках, что показываем во вставке**. Вставки описываем, а не жесты аватара.

```
Реплика. Реплика. (ИИ-аватар + вставка: что показываем)

Реплика. (ИИ-аватар)

Реплика. Реплика. (вставка: что показываем)      ← когда аватара в кадре нет, пишем только вставку
```

Допустимые подписи в скобках:
- `(ИИ-аватар)` — говорящая голова без вставки.
- `(ИИ-аватар + вставка: ...)` — вставка поверх или вместо аватара на этом блоке.
- `(вставка: ...)` — только вставка (аватар не показываем).
- Если жест важен (редко): `(ИИ-аватар поднимает палец вверх, на экране появляются цифры «375$, 2 625$, 11 250$»)`.

Типовые вставки (используем эти, не придумывай экзотику): экран YouTube (поиск вирусного видео, канал, просмотры), экран выплат (сколько платит YouTube/TikTok за 1 млн просмотров), экран ChatGPT (ввод промпта, копирование текста), интерфейс Forge Vision (вставка текста, выбор формата и стиля, кнопка), готовый сгенерированный ролик, статистика канала (просмотры, подписчики, доход), пролистывание стилей Forge Vision, секундомер, демо профиля («шапка профиля»).

Промпт в ChatGPT пиши прямо в скобках: «Напиши уникальный сценарий для минутного видео по теме: [название вирусного видео]. Сделай его динамичным и цепляющим». Переменные в квадратных скобках `[ ]` означают «подставляется».

## Структура ролика
1. **Хук** (1–2 реплики, до 3 секунд): сумма, обещание или вопрос.
2. **Шаги** (4–6 реплик): YouTube → ChatGPT → Forge Vision → результат.
3. **Доказательство:** статистика, просмотры, деньги.
4. **CTA** (последний блок) — база с 26.11.2026, утверждена пользователем:
   «Программа вышла недавно, поэтому первым пользователям раздают подарки: промокоды и бесплатный доступ к полной версии со всеми функциями. Забирай свой по ссылке в шапке профиля. (ИИ-аватар + вставка: плашка «🎁 Подарки первым пользователям — ссылка в шапке профиля», затем демо профиля и переход в Telegram-бота)».
   Мостик — «программа вышла недавно, поэтому…». Подарки называем так: промокоды и бесплатный доступ к полной версии со всеми функциями. Срок не называем. Без слов «подписка», «тариф Про», «демо».

## Правила формулировок (правки пользователя)
- **Без ниши в голосе.** Не пиши «в своей нише», «в нише ИИ», «в любой нише». Просто: «Находишь любое вирусное видео», «Открываешь любой популярный канал и смотришь, сколько он набирает просмотров».
- **Сценарий в ChatGPT — просто сценарий, не «по сценам».** Forge Vision сам делает картинки, анимацию и видео по тексту диктора (что говорит диктор, то и показывает), раскадровка не нужна. Пример: «Просишь написать сценарий для минутного шортса».
- **Формат не называем цифрами.** Не «9:16 / вертикальный», а «выбираешь нужный формат».
- **Без «бум» и подобных междометий.** «Пара минут — и готовый шортс».
- **Без пацанских оборотов** («жёстко», «безумие», «бум», «разнос»): это red flag. Вместо «сохрани, это жёстко» — «сохрани, это полезно» / «сохрани, это важно».
- **Площадку называем, только если показали её выплаты.** Нет строки «а вот сколько платит TikTok» — не пиши «выкладываешь в TikTok», только YouTube.
- **Вставку описывай так, чтобы было понятно, что готовить.** Не «график роста», а «обрезанный скриншот графика просмотров из YouTube Studio (Аналитика → Просмотры), маленькой плашкой». Не «плашка с доходом», а «обрезанный скриншот „Расчётный доход“ из YouTube Studio».
