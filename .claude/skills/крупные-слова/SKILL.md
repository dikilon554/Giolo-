# Стиль «Крупные слова»

Динамичный рилс: склейка на каждом слове или паре слов, на каждой склейке новая крупность с коротким ударом, слова огромными буквами на весь экран. Для коротких роликов и хуков до 30–60 с.

## Что нужно на входе
- Папка с дублями (вертикальное видео 9:16). Путь даёт пользователь. Если не дал — спроси один раз.
- Инструменты: **ffmpeg + whisper + Python (Pillow, numpy)** на этом компьютере. В DaVinci этот стиль делается хуже: ключевые кадры там только скриптом. Если подключён DaVinci — можно собрать в нём, но анимацию слов всё равно рисуй кодом и клади поверх.
- Пользуйся только программами на этом компьютере. Платные сервисы и сайты без разрешения пользователя не открывай.

## Порядок работы

### 0. Подготовка
1. Исходники не трогай. Результаты — в новую папку `монтаж_<дата>` рядом с исходниками.
2. `ffprobe`. Переменная частота кадров (iPhone) → перегони в постоянную (29.97). HDR (HLG/bt2020) → сначала в Rec.709, потом всё остальное. Если в ffmpeg нет фильтров `zscale`/`libplacebo` — переводи через таблицу цвета (.cube), которую сам посчитаешь.
3. Лучше всего, если исходник 4K: на крупных кропах до 2,3× картинка останется чёткой. Из Full HD крупнее 1,6× не бери.
4. Проверь, что в файле есть звуковая дорожка. Нет звука — остановись и скажи пользователю: без речи монтировать по словам нельзя.

### 1. Расшифровка и план
1. Расшифруй каждое слово со временем (whisper с пословными таймкодами).
2. Выбери дубли: фраза повторяется → ПОСЛЕДНИЙ полный дубль целиком. Паузы внутри фразы не режь. Тишину между фразами вырезай (и звук, и картинку) до ~0,1 с — темп выше, чем в спокойных стилях.
3. Разбей речь на группы по 1–2 слова (предлоги и частицы приклеивай к соседнему слову). Отметь 3–5 ключевых слов — они будут красными.
4. Пришли таблицу: группа слов → время → крупность кропа. **Жди «ок».**

### 2. Склейки (суть стиля)
- Новая «склейка» = новая группа слов, примерно каждые 0,5–1 с. Внутри фразы звук не режется: идёт непрерывно, меняется только кадр.
- На каждой склейке своя крупность: кроп от 1,2× до 2,3×, соседние заметно отличаются (не 1,3 после 1,25). Иногда сдвиг центра на ±5 % ширины — только если лицо остаётся целиком в кадре.
- Лицо всегда в кадре: центр кропа по голове (отследи её по кадрам детектором лица, например YuNet из OpenCV), глаза на ~0,34 высоты.
- **Удар-наезд:** первые 0,16 с после склейки кадр на 7 % крупнее и плавно садится на свою крупность (кривая ease-out). Дальше лёгкий дрейф — плюс 2,5 % крупности в секунду, чтобы кадр жил.
- **Вспышка:** в первый кадр склейки белый с прозрачностью ~35 %, один кадр. Не на первой склейке ролика (удар-наезд — на всех, включая первую).
- Цвет чуть сочнее и контрастнее спокойных стилей: насыщенность +20 %, контраст +10 %, лёгкая резкость. Кожа должна остаться кожей.

### 3. Слова на весь экран
- На экране только текущая группа (1–2 слова) — ровно пока она звучит.
- Шрифт: Unbounded Black (или любой широкий жирный), ~118 px на кадр 1080×1920, ЗАГЛАВНЫМИ. Длинное слово уменьшай, чтобы влезло в 960 px ширины.
- Белый текст, чёрная обводка ~7 px. Ключевые слова — красным `#ff3d2e`.
- Появление: слово выскакивает с 125 % до 100 % за 0,13 с.
- Место: по центру по ширине, на ~64 % высоты кадра (ниже лица, на уровне груди). На самых крупных кропах опускай ниже подбородка (до ~75 %). **Не на лице и не на рту.**
- Без размытой тени.

### 4. Экспорт
1080×1920, 29.97 CFR, H.264 High ~20 Мбит/с, Rec.709 (в ffmpeg добавь `setparams=color_primaries=bt709:color_trc=bt709:colorspace=bt709`, иначе в файле останется пометка HDR), AAC 48 кГц, громкость около −14 LUFS. Имя: `<название>_крупные-слова_v1.mp4`.

### 5. Самопроверка (отдельным шагом)
1. Расшифруй готовый ролик: каждая фраза звучит ровно один раз, нет двойных и обрезанных слов.
2. Слово на экране совпадает со звучащим (сверь по 5 точкам; расхождение не больше 2 кадров).
3. Лента кадров раз в 0,5 с: лицо в кадре на каждой склейке, текст не на лице, нет мыла на самых крупных кропах.
4. Посчитай склейки и пришли список «время → слово → ок / исправить» и путь к файлу.

## Файл правил
Каждую правку пользователя («это слово не красным», «здесь мягче») записывай в `правила_монтажа.md` в папке проекта и применяй ко всему ролику и к следующим. Перед работой прочитай этот файл, если он есть.
