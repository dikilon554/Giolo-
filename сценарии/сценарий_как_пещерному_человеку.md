# Как пещерному человеку * (референс: Drive «let me break it down for you #higgsfieldpartner», 64 с, EN)

Вердикт: подходит с адаптацией. Берём не идею (детские шортсы через Higgsfield — повтор), а ПОДАЧУ: «объясняю, как пещерному человеку» — по одному-два слова, каждое слово повторяется, под каждым словом картинка/иконка. Такой подачи у нас ещё не было. ChatGPT + Higgsfield → ChatGPT + Forge Vision. Всё на экране — моушн-графика.

## Сценарий
(аватар говорит медленно, рублено, по одному-два слова, с паузами; под каждым словом — иконка моушн-графикой)

YouTube плюс ИИ — это деньги. Объясняю, как пещерному человеку. (ИИ-аватар + плашка сверху «YouTube + ИИ = 💰 (объясняю как пещерному человеку)», держится весь ролик)

YouTube. Заходи на YouTube. (иконка YouTube)

Видео. Найди видео. Много просмотров. (моушн: превью ролика, счётчик просмотров «1 000 000» набегает)

ChatGPT. Открой ChatGPT. (иконка ChatGPT)

Сценарий. Попроси сценарий. Копируй. (моушн: поле чата, строка «напиши сценарий», значок «копировать»)

Forge Vision. Открой Forge Vision. (заставка с логотипом Forge Vision — моушн в стиле ролика эксперта)

Текст. Вставь текст. (моушн: текст влетает в поле)

Стиль. Выбери стиль. (моушн: сетка стилей, один выделяется)

Кнопка. Жми кнопку. (моушн: нажатие «Создать ролик»)

Ты меня ещё слушаешь? (ИИ-аватар крупно, пауза)

Готово. Мультик готов. Сам. (вставка: готовый ролик Forge Vision на весь экран, 2–3 с)

Выложи на YouTube. Каждый день. (моушн: меню YouTube «Создать → Загрузить видео» — из ролика эксперта ~23 с)

Просмотры. Выплаты. С телефона. (моушн: счётчик просмотров → плашка «Расчётный доход» → иконка телефона)

А теперь нормально: программа вышла недавно, поэтому первым пользователям раздают подарки: промокоды и бесплатный доступ к полной версии со всеми функциями. Забирай свой по ссылке в шапке профиля. (ИИ-аватар обычным темпом + плашка «🎁 Подарки первым пользователям — ссылка в шапке профиля», затем демо профиля и переход в Telegram-бота)

Длительность ≈ 45–50 с.

## Что подготовить
- Только готовый ролик Forge Vision (любой мультик). Всё остальное — моушн-графика.

## Что взяли и что заменили
- Подача «explaining it to you like you're a caveman»: слово → повтор → иконка под словом — оставили.
- «Are you still with me?» — оставили («Ты меня ещё слушаешь?»).
- ChatGPT → плагины → Higgsfield → установить → разрешить → промпт → Forge Vision: текст → стиль → кнопка (без плагинов).
- «Kids YouTube Shorts» → просто «мультик» (без ниши).
- «Printing money. No more work» → «Просмотры. Выплаты. С телефона» (без обещаний «денег без работы»).
- «Comment Astra, I teach you free» → «А теперь нормально:» + наш CTA обычной речью.

## Варианты хука / плашки (1-я реплика)
1) «YouTube плюс ИИ — это деньги. Объясняю, как пещерному человеку.» — «YouTube + ИИ = 💰 (объясняю как пещерному человеку)»
2) «Как сделать ролик для YouTube. Объясняю очень просто.» — «Ролик для YouTube (объясняю очень просто) 🦴»
3) «Канал без лица. Объясняю, как пятилетнему.» — «Канал без лица (объясняю как пятилетнему) 🧸»
