# Ссылка вместо сценария * (новый формат, по ролику эксперта с основного аккаунта)

## Сценарий

Тебе даже не нужно писать сценарий для YouTube-ролика. Смотри. (ИИ-аватар + вставка: плашка сверху «Без сценария. Без съёмок. Без монтажа.»)

Заходишь на YouTube и находишь любое вирусное видео. Смотришь, сколько у него просмотров. (вставка: экран YouTube, вирусный ролик, видно просмотры)

Копируешь ссылку на этот ролик. (вставка, моушн-графика: адресная строка, выделение и копирование ссылки)

Заходишь в Forge Vision. Это настоящая машина по производству шортсов. И просто вставляешь ссылку. (вставка, моушн-графика: заставка с логотипом Forge Vision, затем поле, в которое вставляется ссылка — как в ролике эксперта)

Выбираешь стиль из библиотеки. Их там больше шестидесяти. (вставка: запись экрана из Telegram-приложения — пролистывание библиотеки стилей, выбор одного)

Жмёшь «Создать ролик». Через пару минут у тебя свой ролик на эту тему: с картинкой, анимацией, озвучкой и монтажом. (вставка: кнопка «Создать ролик», затем готовый ролик)

И так можно сделать хоть десять роликов за вечер. (вставка: сетка из нескольких готовых роликов Forge Vision)

Программа вышла недавно, поэтому первым пользователям раздают подарки: промокоды и бесплатный доступ к полной версии со всеми функциями. Забирай свой по ссылке в шапке профиля. (ИИ-аватар + вставка: демо профиля, переход в Telegram-бота)

Длительность ≈ 30–35 с, 8 реплик.

## Варианты хука (1-я реплика, ≈3 с)
1) «Тебе даже не нужно писать сценарий для YouTube-ролика. Смотри.» — плашка «Без сценария. Без съёмок. Без монтажа.»
2) «Хватит искать темы для роликов. Сделай вот что.» — плашка «Искать темы ❌ / Ссылка ✅»
3) «Одна ссылка — и у тебя готовый ролик для YouTube.» — плашка «1 ссылка = 1 ролик»
4) «Каждый день, каждую неделю, каждый месяц. Без единого сценария.» — плашка с цифрами дохода по дням/неделям/месяцам (как у эксперта)

## Подмены вставок
Вирусный ролик и его ссылка · стиль из библиотеки · готовый ролик (тема = тема вирусного ролика) · сетка роликов.

## Монтаж (общим планом)
_Это общий план. Своего конкурента у формата нет — берём подачу ролика эксперта с основного аккаунта (плашка сверху на хуке, записи экрана на весь кадр, заставка Forge Vision с логотипом). По месту дополняй от себя, если нужно._
1. Хук: аватар, сверху плашка «Без сценария. Без съёмок. Без монтажа.»
2. YouTube — запись экрана; копирование ссылки — моушн-графика.
3. «Машина по производству шортсов» — заставка с логотипом Forge Vision и поле со ссылкой — моушн-графикой, как у эксперта (не запись экрана: вставка ссылки есть только в программе для ПК/Mac).
4. Библиотека стилей — быстрое пролистывание.
5. Готовый ролик на весь экран, затем сетка из нескольких роликов.
6. CTA: аватар, плашка «🎁 Подарки первым пользователям — ссылка в шапке профиля», затем демо профиля и Telegram-бот.
