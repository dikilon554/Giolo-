# Один текст — пять стилей * (новый формат)

## Сценарий

Один и тот же текст. И пять совершенно разных роликов. (ИИ-аватар + вставка: сверху плашка «1 текст = 5 роликов», на фоне быстро сменяются 5 версий одного ролика)

Это Forge Vision — машина по производству контента. Ты даёшь ему текст, а он отдаёт готовое видео. (вставка: заставка с логотипом, затем интерфейс)

Смотри. Вставляю один сценарий. (вставка: вставка текста в Forge Vision)

Выбираю аниме — вот такой ролик. (вставка: выбор стиля «Аниме», готовый ролик)

Меняю на фотореализм — уже совсем другое видео. (вставка: выбор стиля «Фотореализм», готовый ролик)

Стикмены, пластилин, старое фото. Стилей там больше шестидесяти. (вставка: быстрая нарезка тех же сцен в стилях «Стикмен цветной», «Пластилин», «Старое фото»)

То есть из одной идеи у тебя пять роликов для пяти разных каналов. (вставка: сетка из 5 готовых роликов)

Программа только вышла, и сейчас первым пользователям дают подарки. Забирай свой по ссылке в шапке профиля. (ИИ-аватар + вставка: демо профиля, переход в Telegram-бота)

Длительность ≈ 30–35 с, 8 реплик.

Что подготовить: один сценарий (тема любая) и 5 готовых роликов по нему в стилях Аниме, Фотореализм, Стикмен цветной, Пластилин, Старое фото.

## Варианты хука (1-я реплика, ≈3 с)
1) «Один и тот же текст. И пять совершенно разных роликов.» — плашка «1 текст = 5 роликов»
2) «Угадай, какой из этих роликов сделан за две минуты? Все пять.» — плашка «Все 5 — за пару минут»
3) «Это один сценарий. Просто в разных стилях.» — плашка «Один сценарий — 5 стилей»
4) «Пять каналов из одной идеи. Показываю как.» — плашка «5 каналов из 1 идеи»

## Подмены вставок
Тема сценария · набор из 5 стилей (любые из 60+) · сетка роликов.

## Монтаж (общим планом)
_Это общий план. Своего конкурента у формата нет. По месту дополняй от себя, если нужно._
1. Хук: аватар на фоне быстро сменяющихся пяти версий одного кадра, плашка «1 текст = 5 роликов».
2. Заставка с логотипом Forge Vision, затем интерфейс и вставка текста.
3. На каждый стиль: клик по стилю → 1–2 с готового ролика; на «стикмены, пластилин, старое фото» — быстрая нарезка по 0,5 с.
4. Сетка 5 роликов одновременно.
5. CTA: аватар, плашка «Подарок первым пользователям — ссылка в шапке профиля 🎁», затем демо профиля и Telegram-бот.
