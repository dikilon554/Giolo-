# Обложки к постам Telegram-канала — единый шаблон

Цель: все обложки в одном стиле, без разнобоя. Меняются только текст и эмодзи, всё остальное фиксировано.
Генератор: `scripts/cover.py` (пример запуска — в начале файла). Утверждено Алексеем 28.11.2026.

## Эталон
Лучшие из старых обложек: «Обновление серверов», «Генерация превью», «4 правила безопасности».
Исходники лежат в Google Drive, папка «ИИ агент».

## Что фиксировано
- Формат 1280×720 (16:9), JPG.
- **Фон**: с обложки «3 функции» (`assets/cover/bg_base.png`): чёрный, оранжевые диагональные полосы, сетка.
- **Логотип FM** слева сверху (`assets/cover/fm_logo.png`).
- **Заголовок** в 2 строки, Montserrat Black, сжатый по ширине (74%), все буквы заглавные:
  1-я строка белая, 2-я оранжевая (переход сверху вниз). Короткие строки: 1–3 слова.
- **Плашка** под заголовком: тёмная, тонкая обводка, оранжевая линия снизу; текст «белое + ОРАНЖЕВОЕ слово».
- **Предметы — строго**: один главный предмет справа (~230 px), максимум ещё один мелкий. Без россыпи эмодзи.
  Основа — 3D-объекты в стиле бренда (чёрный глянец + оранжевый) и/или моушен; эмодзи Apple — только запасной
  вариант, если 3D-объекта под тему нет (разрешены открыто).
- **Неона мало**: у заголовка почти нет свечения, только лёгкое тёплое у оранжевой строки.

## Чего не делать
- Не размывать эмодзи (на маленьких картинках это мутные пятна).
- Не добавлять яркий неон, новые цвета, другие шрифты и фоны.

## 3D-объекты бренда (основа)
`assets/cover/objects/` — вырезаны из старых обложек Forge Media (BiRefNet, лицензия MIT; кнопка YouTube — маской по цвету):
`trophy`, `trophy_2` (кубок с F), `coin_f`, `coin_f_2` (монета с F), `youtube` (3D-кнопка), `people` (фигурки + монета),
`servers` (серверная стойка), `pen` (ручка). Ставятся так же: `--obj trophy:1110:390:330` (высота в px).
Заголовок сам сдвигается левее и сужается, чтобы не залезать на предмет справа.
Новый объект из картинки: `scripts/cut_object.py` (нужна модель BiRefNet_lite ONNX с huggingface, см. код).
В планах на неделе: новые объекты (Blender), живые обложки (GIF/моушен).

## Эмодзи
Лежат в `assets/cover/emoji/` — Apple, 160 px (из репозитория iamcal/emoji-data, папка `img-apple-160`,
качается через raw.githubusercontent.com). Новое эмодзи: имя файла из `emoji.json` → скачать туда же.
Главный предмет не крупнее ~240 px, иначе станет мягким.

## Отправка
Сначала обложка, следом текст: `python3 scripts/tg_send.py посты/<пост>.html --photo посты/<обложка>.jpg`.
